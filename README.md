# DocQandA

**DocQandA** is a practice project built in **ASP.NET MVC** to explore AI model integration.  
The application allows users to upload a text document and ask questions about it. It uses:

- **Hugging Face** embeddings (`sentence-transformers/all-MiniLM-L6-v2`) for semantic understanding of the document.  
- **Groq LLM** for generating answers based on the best-matched content chunk.  

> This is a learning/practice project for integrating AI models into a .NET application.

---

## Features

1. **Landing Page**
   - Introduces the application.
   - Includes a "Start" button to begin.

2. **Document Upload**
   - Users can upload `.txt` files (size limited for safety).  
   - Document is split into chunks, and embeddings are generated.  

3. **Chat Interface**
   - Ask any question related to the uploaded document.  
   - Responses are generated by **RAG (Retrieval-Augmented Generation)** using Hugging Face + Groq.  
   - Chat-like interface (conversation not persisted).  

4. **Error Handling & Security**
   - Validates file upload types and sizes.  
   - Handles external service unavailability gracefully.  
   - Logs errors for debugging.  
   - Uses HTTPS by default.  

---

## Technology Stack

- **.NET 9 / ASP.NET MVC**
- **Microsoft Semantic Kernel**
- **Groq LLM** (for AI reasoning)
- **Hugging Face API** (for text embeddings)
- **Bootstrap / CSS** for simple responsive UI
- **C# 12**
